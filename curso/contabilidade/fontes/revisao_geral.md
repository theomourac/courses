## 3. O fio que liga tudo

📘 O curso gira em torno de três perguntas, cada uma respondida por uma demonstração (slide "Visões das Principais Demonstrações Contábeis"):

| Visão | Perguntas | Demonstração |
| --- | --- | --- |
| Posição patrimonial e financeira | Onde se investe? Como se financia? Consegue pagar os passivos? | **Balanço Patrimonial** (fotografia em uma data) |
| Eficiência e desempenho econômico | Dá lucro? Quanto fatura? O resultado é operacional ou financeiro? | **DRE** (filme do período, regime de competência) |
| Mutações na posição financeira | O que acontece com o caixa? Gera caixa? Onde consome? | **DFC** (filme do caixa, regime de caixa) |

📘 **As conexões que caem em prova:**
1. **DRE → BP:** o lucro líquido da DRE entra no PL (lucros/resultados acumulados); prejuízo reduz o PL. Dividendos saem do PL. PL final = PL inicial + LL + aportes − dividendos.
2. **DFC → BP:** a DFC explica a variação da conta Caixa e equivalentes entre dois balanços (saldo inicial + FCO + FCI + FCF = saldo final).
3. **DRE ↔ DFC:** a DFC indireta parte do lucro líquido e o ajusta por itens sem caixa (depreciação, amortização) e pela variação do capital de giro operacional. Lucro ≠ caixa.
4. **BP → indicadores:** liquidez e endividamento usam só o BP; rentabilidade usa DRE sobre BP (ROA, ROE, giro); capital de giro usa o circulante do BP e prazos que misturam BP e DRE.
5. **Tributação → DRE:** tributos sobre faturamento (ISS, ICMS, PIS, COFINS, IPI) são **deduções** da receita bruta; tributos sobre o lucro (IRPJ, CSLL) ficam **depois do LAIR**.
6. **Matemática financeira → tudo:** dinheiro tem valor no tempo; inflação separa ganho nominal de ganho real (por isso a análise compara margens e crescimento com o IPCA).

```
          Balanço inicial ──► DRE (competência) ──► LL ──► PL do balanço final
                 │                                            ▲
                 └──► DFC (caixa): FCO + FCI + FCF ──► Caixa do balanço final
```

## 4. Formulário completo (memorize — a prova é sem consulta)

### 4.1 Matemática financeira
| Fórmula | Uso |
| --- | --- |
| J = C · i · n ; M = C (1 + i · n) | juros simples (linear) |
| i = J / (C · n) ; n = J / (C · i) ; C = M / (1 + i · n) | isolar variáveis no simples |
| M = C (1 + i)^n ; C = M / (1 + i)^n ; J = M − C | juros compostos (exponencial) |
| i_k = i / k | taxa proporcional (simples): 30% a.a. → 2,5% a.m. |
| i_quero = (1 + i_tenho)^(quero/tenho) − 1 | taxa equivalente composta: 1% a.m. → 12,68% a.a. |
| nominal x% a.a. cap. mensal → x/12 a.m. e depois compõe | taxa nominal: 24% a.a. cap. mensal → 2% a.m. → 26,82% a.a. efetiva |
| (1 + i_ac) = (1 + i₁)(1 + i₂)…(1 + iₙ) | taxa acumulada (nunca some as taxas) |
| (1 + nominal) = (1 + real)(1 + inflação) | Efeito Fisher; real = (1 + nom)/(1 + infl) − 1 |
Regra de ouro: **taxa e prazo na mesma unidade**. No 1º período simples = composto; em fração de período o simples rende mais.

### 4.2 Balanço patrimonial
| Fórmula | Uso |
| --- | --- |
| Ativo = Passivo + PL ; PL = Ativo − Passivo | equação fundamental |
| Ativo = aplicações (investimento) ; Passivo + PL = origens (financiamento) | leitura das colunas |
| Capital de terceiros = Passivo ; Capital próprio = PL ; Capital total = Ativo | fontes |
| Circulante = até 12 meses ; Não circulante = após 12 meses | classificação |
| Ativo ordenado por liquidez ; Passivo + PL por exigibilidade | ordem das contas |
| PL final = PL inicial + aumento de capital + LL − dividendos (− prejuízo) | evento × PL |

### 4.3 DRE
```
  Receita Bruta
(−) Deduções (impostos sobre vendas, devoluções/vendas canceladas, abatimentos, descontos incondicionais)
(=) Receita Líquida
(−) CPV / CMV / CSP
(=) Lucro Bruto
(−) Despesas operacionais (vendas, administrativas, outras) (+ outras receitas operacionais)
(=) Lucro Operacional = EBIT
(+) Receitas financeiras (−) Despesas financeiras (± resultado não operacional)
(=) LAIR
(−) IR e CSLL
(=) Lucro Líquido
```
EBITDA = EBIT + Depreciação + Amortização · Lucro Real (LALUR) = LAIR + adições − exclusões · IR 25% (15% + 10% adicional) + CSLL 9% = **34% "combinado"**.

### 4.4 DFC
| Fórmula | Uso |
| --- | --- |
| Saldo inicial + FCO + FCI + FCF = saldo final | conciliação com o BP |
| FCO indireto = LL + depreciação/amortização − ↑ativo operacional + ↓ativo operacional + ↑passivo operacional − ↓passivo operacional | método indireto |
| Operacional: clientes, fornecedores, salários, impostos, juros recebidos (curso) | classificação |
| Investimento: compra/venda de imobilizado, intangível, participações, empréstimos concedidos | classificação |
| Financiamento: empréstimos captados/amortizados, emissão/recompra de ações, dividendos pagos | classificação |
Não mexem no caixa: depreciação, amortização, provisões, receita a prazo ainda não recebida, compra a prazo ainda não paga.

### 4.5 Análise vertical, horizontal e variação monetária
| Fórmula | Uso |
| --- | --- |
| AV = conta / base × 100 | base = Ativo Total (BP) ou Receita Líquida (DRE) |
| AH = (valor atual / valor anterior − 1) × 100 | evolução % |
| Variação monetária = valor atual − valor anterior | evolução em R$ |
| Variação de indicador = (indicador ano 2 / indicador ano 1 − 1) × 100 | AH sobre margens |

### 4.6 Rentabilidade
| Fórmula | Leitura |
| --- | --- |
| Rentabilidade = ganho / investimento | 30/200 = 15% |
| Margem bruta = LB / RL ; operacional = EBIT / RL ; líquida = LL / RL ; EBITDA = EBITDA / RL | quanto sobra de cada R$ 1 vendido |
| ROA = LL / Ativo Total | lucro por R$ 1 de ativo |
| ROE = LL / PL | lucro por R$ 1 dos sócios |
| Giro do ativo = RL / Ativo Total | vendas por R$ 1 de ativo |
| Alavancagem (MPL) = Ativo Total / PL | mínimo 1 (100% capital próprio) |
| **ROE = ML × Giro × Alavancagem** ; ROA = ML × Giro | DuPont |

### 4.7 Liquidez, solvência e estrutura
| Fórmula | Melhor quando |
| --- | --- |
| Liquidez corrente = AC / PC | maior (> 1) |
| Liquidez seca = (AC − Estoques) / PC | maior (> 1) |
| Liquidez imediata = (Caixa + Aplicações) / PC | maior |
| Endividamento geral = (PC + PNC) / AT | menor; > 1 = passivo a descoberto (PL negativo) |
| Solvência geral = AT / (PC + PNC) | maior; < 1 = passivo a descoberto |
| Grau de endividamento = Participação de capital de terceiros = (PC + PNC) / PL | menor (slide: > 3 = dependência elevada) |
| Cobertura de juros = EBIT / Despesas financeiras | maior |
| Composição do endividamento = PC / (PC + PNC) | menor (dívida mais longa) |
| Imobilização do PL = ANC / PL | menor (slide: > 2 = elevada) |

### 4.8 Capital de giro e ciclos
| Fórmula | Leitura |
| --- | --- |
| CGL = AC − PC = NIG + ST | > 0: recursos de longo prazo financiando o curto prazo |
| NIG (NCG) = ACO − PCO | > 0: a operação precisa de dinheiro |
| ST = ACF − PCF | < 0: dívida de curto prazo financiando a operação |
| Impacto no caixa = − ΔNIG | NIG sobe → consome caixa |
| PMR = Contas a receber / Receita × 365 | dias para receber |
| PMP = Fornecedores / Compras × 365 | dias para pagar |
| PME = Estoques / CMV × 365 | dias em estoque |
| Compras = Estoque final + CMV − Estoque inicial | para o PMP |
| Ciclo operacional = PME + PMR ; Ciclo de caixa (CCC) = PME + PMR − PMP | dias a financiar |
Gestão: equilibrada (CGL = NIG, ST = 0) · conservadora (CGL > NIG, ST > 0) · agressiva (CGL < NIG, ST < 0) · muito agressiva (CGL < 0). ACO = clientes, estoques, despesas antecipadas · PCO = fornecedores, salários, impostos · ACF = caixa, aplicações · PCF = empréstimos, financiamentos, debêntures, dividendos a pagar.

## 6. Estratégia para a prova (sem consulta)

1. **Antes de calcular, identifique o tema e a fórmula.** Escreva a fórmula na folha antes dos números: mesmo se errar a conta, a memória de cálculo mostra o raciocínio.
2. **Matemática financeira:** confira a unidade (taxa a.m. × prazo em meses). Procure as palavras "simples", "compostos", "capitalizada mensalmente", "equivalente", "proporcional", "acumulada", "real", "nominal". Juros ≠ montante: leia o que se pede.
3. **Balanço:** para cada evento, pergunte "mexe no PL?" Só mexem: aporte de capital, lucro/prejuízo, dividendos (e receitas/despesas). Empréstimo, compra de ativo, pagamento de dívida **não** mexem no PL.
4. **DRE:** escreva a escada completa, linha por linha, mesmo que o enunciado pule etapas. Impostos sobre vendas são dedução; IR/CSLL vêm depois do LAIR.
5. **DFC:** "mexeu no dinheiro?" Depreciação, provisão e venda a prazo não. Investimento = ativo de longo prazo; financiamento = sócios e credores financeiros.
6. **Indicadores:** escreva a fórmula com os nomes das contas; cuidado com o que vai no numerador e no denominador; interprete em uma frase ("para cada R$ 1 de…").
7. **Arredondamento:** carregue 4 casas nos fatores e arredonde só no final (R$ com 2 casas, % com 2 casas).
8. **Interpretação vale ponto:** a lista pede "explique em uma frase", "aumentou, diminuiu ou ficou igual", "qual regime seria mais vantajoso". Responda explicitamente.
9. **Sinais:** AH negativa é queda; NIG subindo consome caixa; ST negativo é gestão agressiva; PL negativo = passivo a descoberto.
10. **Leia as dicas do enunciado** ("Atenção: um dos dois eventos não afeta o PL"): são pegadinhas anunciadas.
11. **Calculadora científica:** potência com `^` (ou `xʸ`), expoente fracionário sempre entre parênteses (`1.58 ^ (1 ÷ 12)`), taxa digitada como fator (1,035, sem a tecla `%`), resultado intermediário guardado em `Ans`/memória e arredondado só no fim. Passo a passo na seção 3.12 de `link_contabilidade_matematica_financeira`.

## 7. Top 30 armadilhas (todas as matérias)

1. ⚠️ Somar taxas compostas em vez de multiplicar fatores: 1,5% seguido de 2% acumula (1,015 × 1,02) − 1 = 3,53%, não 3,5%.
2. ⚠️ Dividir taxa composta pelo número de meses (58% a.a. ÷ 12 = 4,83% está errado; o certo é 1,58^(1/12) − 1 = 3,89% a.m.).
3. ⚠️ Taxa nominal com capitalização: primeiro divide (proporcional), depois compõe.
4. ⚠️ Fisher: real = 1,12/1,06 − 1 = 5,66% (não 12% − 6% = 6%).
5. ⚠️ "Juros" × "montante": a questão pede um e você entrega o outro.
6. ⚠️ Prazo em anos e meses misturados ("1 ano e 11 meses" = 23 meses).
7. ⚠️ Empréstimo captado **não** altera o PL (aumenta ativo e passivo).
8. ⚠️ Venda de imobilizado à vista: AC aumenta pelo valor **recebido**, não pelo valor contábil (Q13 do simulado).
9. ⚠️ Compra de estoque à vista não muda o AC (troca caixa por estoque).
10. ⚠️ Marca criada internamente não é ativo; marca comprada é (intangível).
11. ⚠️ Mercadoria deteriorada e título incobrável deixam de ser ativo (não geram benefício).
12. ⚠️ Propriedade jurídica não é obrigatória para ser ativo: o que importa é o **controle** (leasing financeiro).
13. ⚠️ Receita bruta não é a receita "real": a real é a receita líquida.
14. ⚠️ IPI na nota: incide sobre o preço com ICMS; a receita bruta inclui o IPI (exemplo 66.000 + 33.000 = 99.000).
15. ⚠️ Receitas e despesas financeiras não são operacionais (ficam abaixo do EBIT).
16. ⚠️ Depreciação reduz o lucro, mas não o caixa — e é somada de volta na DFC indireta.
17. ⚠️ No método indireto, **aumento** de clientes/estoques **subtrai**; aumento de fornecedores **soma**.
18. ⚠️ Pagamento de dividendos é financiamento; recebimento de juros de aplicações é operacional (convenção do curso).
19. ⚠️ Competência: o custo da mercadoria vendida é só da parte vendida (60% de 12.000 = 7.200), não do total comprado.
20. ⚠️ AV da DRE usa a receita líquida como base; AV do BP usa o ativo total.
21. ⚠️ AH negativa: escreva o sinal (−16,1%) e interprete como queda.
22. ⚠️ Liquidez seca tira só os estoques; liquidez imediata usa só caixa + aplicações.
23. ⚠️ Endividamento geral divide pelo **ativo**; grau de endividamento divide pelo **PL**.
24. ⚠️ Alavancagem (MPL) = AT/PL, não Passivo/PL (AT/PL = 1 + Passivo/PL).
25. ⚠️ ROE alto pode vir de alavancagem (mais risco), não de eficiência — olhe a DuPont.
26. ⚠️ NIG positiva crescendo consome caixa mesmo com lucro (empresa lucrativa pode quebrar por falta de caixa).
27. ⚠️ Caixa e aplicações entram no **ACF**, não no ACO (salvo "caixa operacional" explícito); empréstimos de curto prazo são **PCF**.
28. ⚠️ Lucro Presumido: a base é **receita × presunção**, não o lucro; o adicional de 10% só incide sobre a base acima de R$ 20 mil/mês.
29. ⚠️ Margem real abaixo da presunção → Lucro Real tende a compensar; margem acima → Presumido.
30. ⚠️ Taxa (coleta de lixo) ≠ imposto (ICMS) ≠ contribuição de melhoria (pavimentação); elisão é legal, sonegação é crime.

## 10. Protocolo para sessões de estudo

- **Modo EXPLICAR:** identificar o tema, carregar a skill do tema e explicar do zero: intuição → definição do curso → fórmula → exemplo dos slides → pegadinha.
- **Modo EXERCITAR:** uma questão por vez (do `exercicios.md` desta skill ou do banco da skill do tema), esperar a resposta do aluno, corrigir mostrando conta e conceito, manter um placar por tema e voltar nos erros com uma questão parecida.
- **Modo SIMULADO:** aplicar o Simulado A, B, C ou D (ou um sorteio de questões de todas as skills, na proporção da seção 5) sem dar feedback no meio; no fim, corrigir tudo, dar a nota (0 a 10), o diagnóstico por tema (acertos/total) e um plano de reforço apontando a skill de cada tema fraco.
- **Modo FORMULÁRIO:** pedir ao aluno que escreva de memória as fórmulas de um tema e conferir com a seção 4.
- Sempre exigir memória de cálculo e uma frase de interpretação; a prova é sem consulta, então reforce a memorização.
- Ao gerar questões novas, verificar as contas (Python) antes de apresentar o gabarito.
